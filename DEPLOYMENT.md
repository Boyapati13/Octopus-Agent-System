## Step 7 — Create ECC Rules Directory

The `.claude/rules/` directory is where ECC guardrails live. Create it:

```powershell
New-Item -ItemType Directory -Path ".claude\rules" -Force

# Add the ECC node.js rules (copied from ECC repo)
@"
---
description: Node.js coding standards (ECC-aligned)
alwaysApply: true
---
- CommonJS only (no ESM unless .mjs)
- Use const over let, never var
- Hook scripts must exit 0 on non-critical errors
- console.error for diagnostics, never console.log in production paths
- All hooks must complete PreToolUse in <200ms
"@ | Out-File -FilePath ".claude\rules\node.md" -Encoding utf8

# Add the security guardrails
@"
---
description: Security guardrails (ECC + AgentShield)
alwaysApply: true
---
- Never hardcode secrets — all credentials via environment variables
- Run AgentShield scan before every deploy (AGENTSHIELD_MODE=gate for prod)
- Validate agent names: /^[a-zA-Z][a-zA-Z0-9_]{0,63}$/
- No eval(), new Function(), or __proto__ assignments
- All database queries through repository layer
"@ | Out-File -FilePath ".claude\rules\security.md" -Encoding utf8

Write-Host ".claude/rules/ created with 2 ECC guardrail files ✅"
```

## Troubleshooting

| Issue | Cause | Fix |
|---|---|---|
| `python` not found | Python not in PATH | Use `py` instead of `python` (Python Launcher installed) |
| `MODULE_NOT_FOUND` in mcp.js | Wrong working directory | Always run from `node/` or use absolute path |
| MCP tools not appearing | Config file path wrong | Ensure `%APPDATA%\Claude\` exists, double-check `\\` escaping |
| Memory service 503 | Flask not running | Run `py python\services\memory_service.py` first |
| Instincts table missing | DB not initialized | Run the indexer (Step 3) or start memory service (creates schema) |
| AgentShield not blocking | SAFE_MODE=true | Set `SAFE_MODE=false` in .env and MCP env config |
| Gemma 4 slow | Model too large | Try `gemma3:4b` for faster responses; keep `gemma4:e2b` for quality |
| `PROJECT_ROOT` not injected | Env var not set | Add to claude_desktop_config.json `env` block (see Step 4) |
