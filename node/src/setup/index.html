Messaging Gateways
Connect messaging platforms — all optional, can be added later
ℹ️ Gateways let users talk to Octopus via Telegram, Discord, Slack and more. Enable and configure whichever platforms you use. All are optional.
✈️ Telegram Not configured
📌 Create a bot via @BotFather on Telegram → /newbot → copy the token.
Leave blank to allow all users. Find your ID via @userinfobot
OCTO will forward answers here. Find chat ID via @userinfobot or send a message to the bot first.
🎮 Discord Not configured
📌 Go to discord.com/developers → New Application → Bot → Copy Token. Enable Message Content Intent.
💚 Slack Not configured
📌 Create a Slack app at api.slack.com/apps. Enable Socket Mode, add Bot Scopes: chat:write, im:history, app_mentions:read.
📱 WhatsApp Not configured
Folder where session keys are persisted across restarts
📱 Scan with WhatsApp → Linked Devices → Link a Device
QR refreshes every 30s automatically
🔒 Signal Not configured
📌 Requires signal-cli installed and registered. Run signal-cli -u +YOURPHONE register first.
🏠 Home Assistant Not configured
📌 Generate a Long-Lived Access Token in Home Assistant → Profile → Long-Lived Access Tokens.
