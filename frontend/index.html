⚡ Quick Setup

  • Get a free Gemini API key at aistudio.google.com
  • Add it to config/api_keys.json as gemini_api_key
  • Install deps: pip install google-genai aiohttp websockets
  • Start voice service: python python/services/voice_service.py
  • Click Start Voice and allow microphone access
